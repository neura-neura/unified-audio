# Feature parity matrix

Status vocabulary: `Audited` means the exact upstream behavior and destination are identified; `In progress` means production code exists but acceptance evidence is incomplete; `Verified` requires the named automated test or reproducible manual evidence; `Replaced` requires an equivalent-or-better implementation and proof. Screens alone never qualify.
